shroomcoin

shroomcoin is a joke. it is not an investment, it has no value, nobody is going to buy it from you, and nothing on this page is financial advice.

what is it

  • an ERC-20 token on Arbitrum that gets given to people who find large mushroom islands in Minecraft.

what is it not

  • an investment
  • a get rich quick scheme
  • an offical project of Minecraft@Home

tokenomics

every seed you find is a candidate for a payout, once an island on a seed has paid out, you cannot submit a second island on that same seed

payout = u * 32^(x - 10) * (1 - 2^(6.5 - x))^(n - 1) SHROOM
  • x = island size in millions of blocks (divided by 16 for large biome submissions)
  • u = 1, or 0.65 if the island is beyond the standard 30M world border (unbounded)
  • n = how many islands within the same 250k band have been found so far

the payout formula is based off the rough approximation that finding an island with an extra million blocks in size (or 16M in large bioms) is 32x rarer.

submitting an island

submitting an island requires giving it to a trusted minter who will validate the size and pay the gas to mint your tokens, as a reward for doing this the minter will receive an additional 1% of the total minted value.

currently there is no automated mechanism for submitting new finds, this will change soon.
